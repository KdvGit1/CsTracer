Collision meshes are Valve game assets, distributed by the Awpy data project for community analysis tools.
Source: https://github.com/pnxenopoulos/awpy-data/releases/tag/2000899
ClientVersion: 2000899. Original geometry ZIP SHA256: f89dad57c48e8b02dcb579f9db3ca7dedf512f5580884fc47a650e42a01a1294

These are simplified static occlusion meshes, not visual game models or full material/penetration meshes. Dynamic doors and breakables are not reconstructed. Missing exact demo build information is reported as version-unverified; a known mismatch disables geometry for that analysis. Per-map compressed hashes are recorded in manifest.json. Run launcher/install-geometry.ps1 to refresh the pinned release explicitly.
